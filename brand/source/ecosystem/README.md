# Organization source

`approved-composition.png` is the unchanged approved mountain-and-ink reference. Its
checkerboard is part of the source pixels. Use the released files under `brand/ecosystem/`
for display; `tooling/build-ecosystem.mjs` reconstructs their transparency and composes
the exact existing signature paths.

`mountain-icon.svg` and `mountain-icon-dark.svg` are editable vector masters of the
mountain and ink loop. They generate the compact SVG, PNG, ICO, touch icon, and avatar
exports. The social preview uses the full illustrated logo.
